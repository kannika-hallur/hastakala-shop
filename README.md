# Hasta-Kala Shop

## 📌 Problem Statement
Local handmade artisans do not have a proper digital platform to showcase and sell their handmade products easily.

## 💡 Solution
Hasta-Kala Shop is an Android application that provides a simple and clean interface for browsing handmade products.

## ✨ Features
- Product listing UI
- Clean and simple Android interface
- Easy navigation
- Organized theme-based UI (Jetpack Compose / XML)

## 🛠️ Tech Stack
- Kotlin
- Android Studio
- Jetpack Compose / XML UI
- Material Design

## ▶️ How to Run
1. Clone the repository
2. Open in Android Studio
3. Sync Gradle
4. Run on emulator or physical device

## 📱 Outcome
A simple and user-friendly mobile UI for showcasing handmade products in a digital format.
